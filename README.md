# Что такое VoidData?

**VoidData** — это легковесная бессерверная платформа реального времени (мессенджер и каталог данных), созданная как простая и производительная альтернатива Firebase.

---

### Архитектура и технологии

* **Backend:** Cloudflare Workers (serverless edge-вычисления с мгновенным откликом по всему миру).
* **База данных:** Cloudflare KV (быстрое распределённое хранилище формата ключ-значение).
* **Frontend:** Чистый HTML5 / JavaScript без тяжёлых библиотек и сторонних фреймворков.

---

### Основные возможности

1. **Постоянное хранение:** Сообщения и проекты сохраняются в постоянную память `VOID_KV` и не сбрасываются при закрытии вкладки или перезапуске воркера.
2. **Realtime онлайн-трекер:** Отслеживание активных пользователей в сети через механизм периодических сигналов (*heartbeat*) с автоматическим удалением неактивных сессий по TTL (без фоновых демонов и очисток вручную).
3. **Обмен данными и файлами:** Поддержка отправки текстовых сообщений, публикации проектов и прямой загрузки/выгрузки бинарных файлов через эндпоинты `/publish` и `/download`.
4. **Автономность:** Полный отказ от сторонних баз данных и сложных SDK — вся логика работает на прямых REST API вызовах с поддержкой CORS.
